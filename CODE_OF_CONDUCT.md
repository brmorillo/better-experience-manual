# Code of Conduct / Código de Conduta

## English

This is a project by players, for players. So everyone feels welcome:

- **Be respectful.** Critique the text, not the person. No insults, harassment, discrimination or personal attacks.
- **Be patient with newcomers**, to the game and to Git.
- **Help get it right.** Disagree with something? Show how you checked it in game.
- **No spam and no ads.**
- **No unmarked spoilers** and no cheats that ruin other people's game.

Maintainers may edit, reject or remove contributions, comments and tips that break these rules, and block repeat offenders. To report a problem, open an Issue or, for something personal, use the contact on the maintainer's GitHub profile.

## Português

Este é um projeto de jogadores para jogadores. Para todo mundo se sentir à vontade:

- **Respeito.** Critique o texto, não a pessoa. Nada de ofensa, assédio, preconceito ou ataque pessoal.
- **Paciência com quem está começando**, no jogo e no Git.
- **Ajude a acertar.** Discordou de uma informação? Mostre como conferiu no jogo.
- **Sem spam e sem propaganda.**
- **Sem spoiler sem aviso** e sem trapaças que estraguem o jogo de outras pessoas.

Quem cuida do repositório pode editar, recusar ou apagar contribuições, comentários e dicas que não sigam estas regras, e bloquear quem insistir. Para avisar de um problema, abra uma Issue ou, se for algo pessoal, use o contato do perfil do mantenedor no GitHub.
