# Page templates / Modelos de página

Copy the template into the right `docs/<language>/` folder, rename it (e.g. `03-carpentry.md`) and fill it in. Lines between `<!--` and `-->` are instructions that never show: you can delete them.

> 🇧🇷 Copie o modelo para a pasta certa de `docs/<idioma>/`, renomeie (ex.: `03-carpintaria.md`) e preencha. As linhas entre `<!--` e `-->` são instruções e não aparecem em lugar nenhum: pode apagar.
