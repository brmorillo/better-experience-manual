# More features

Smaller features of the mod, each with its own page:

- **Drink from bags**: the game's auto-drink also uses the water in your bags.
- **Highlight combat area**: while aiming a melee weapon, shows the reach of the swing and who it would hit.
- **Automatic fishing**: the character fishes on its own, eats, drinks and stores the fish.
- **Pause when a zombie gets close**: pauses the game when a zombie comes near while the character is doing something on its own.
- **Auto foraging**: with the game's search mode on, the character walks to the items found and picks them up.
- **Speed up automatic tasks**: automatic fishing and organizing run with the game sped up (single player only).
- **Take food off the heat when done**: food that finished cooking goes to the inventory before it burns.
- **Inventory: All nearby and search**: a button that joins every nearby container in one list and a search box in the inventory and loot window, plus the freshness bar in the food tooltip.

All of them can be turned off in **Options > Mods > Better Experience - ALL In One > Mod features**. The speed-up is in **Automatic tasks** and is off by default.
