# Speed up automatic tasks

While **Automatic fishing** or **base organizing** runs, the mod sets the game to the chosen speed and goes back to normal when the task ends. That way you do not wait for the character to fish in real time.

## Speeds

- **Off** (default): the mod does not touch the speed.
- **x5 (fast)**.
- **x20 (faster)**.
- **x40 (fastest)**.

## When it goes back to normal

- When the task **ends** or you stop it.
- When a zombie **comes near** (within the **Pause when a zombie gets close** distance) or **chases** the character. If the game pauses, **Space** resumes at normal speed.

## Game limits

- **While walking, it stays at x5 at most**: above that the game itself cancels the walk. So while the character walks to a piece of furniture or to the water, the speed stays at x5 and then goes up again.
- **Auto foraging is not sped up**: the game's search only finds items at normal speed.
- **Single player only**: in multiplayer nobody changes the server's speed.

## You are in charge

- If you change the speed in the middle of the task, the mod leaves it as you set it.
- If you set it back to normal speed, it speeds up again.
- With the game paused, the mod does not touch it.

## Options

- **Options > Mods > Better Experience - ALL In One > Automatic tasks > Speed up automatic tasks**: off, x5, x20 or x40. Default: off.
