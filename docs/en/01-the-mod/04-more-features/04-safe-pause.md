# Pause when a zombie gets close

While the character is doing something on its own, the mod **pauses the game** when a zombie comes near. That way you don't lose your character while reading a book or fishing with the game sped up.

## When it pauses

The game pauses when a **new** zombie enters the chosen distance while the character is:

- fishing with **Automatic fishing**;
- **organizing** the base or storing the inventory;
- doing an **action with a progress bar**, such as reading, crafting, reloading or sewing;
- in **search mode** (searching the area).

A message shows up: "Paused: 2 zombie(s) nearby while fishing. Press Pause to continue."

## How to continue

Press **Pause** (or **Space**). The game resumes **at the same speed** it was running.

## What does not pause

- Each zombie pauses **only once**. If you carry on with it nearby, the game will not pause again because of it. If it leaves the distance and comes back, it counts as new.
- A zombie that was already near when the action started does not pause.
- Standing still or walking, without doing anything on its own, the game does not pause.

## In multiplayer

Nobody can pause a server. Instead of pausing, you see "Watch out: 2 zombie(s) nearby while fishing!", a sound plays and the mod turns off automatic fishing and organizing if they are running.

## The distance

Counted in tiles, on the same floor and on the floors right above and right below. The default is **15 tiles**, from 5 to 40.

## Options

- **Options > Mods > Better Experience - ALL In One > Mod features > Pause when a zombie gets close**: turns it on and off.
- **Zombie distance that pauses**: from 5 to 40 tiles.
