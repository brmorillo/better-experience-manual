# The mod

**Better Experience - ALL In One** bundles several quality-of-life improvements.

## Use only what you want

Every part of the mod can be turned off in **Options > Mods > Better Experience - ALL In One > Mod features**: base organizer, food by expiration, map item search, GPS, compass bar, drinking from bags, automatic fishing, auto foraging, taking food off the heat, combat area, pause when a zombie gets close and the manual. Only want the GPS and the compass? Turn the rest off.

A feature that is off leaves the menus, the map and the hotkeys, stops running and writes nothing new to your save. See **Options** for the details.

## Where everything is

- **Right-click the floor or a piece of furniture** > **Better Experience - ALL In One**: organize your base, food by expiration, map search, GPS and this manual. On water, automatic fishing. With the game's search mode on, auto foraging (also from the right-click on an item found by the search).
- **On the map** (M key): the **Better Experience** button, with the **Items** and **Favorites / GPS** tabs (only for features that are on).
- **Options** > **Mods** > **Better Experience - ALL In One**: turn each feature on or off, every setting and the hotkeys.

## Hotkeys

No key is bound by default, so the mod never clashes with other mods. Pick yours in **Options > Mods > Better Experience - ALL In One > Hotkeys**.
