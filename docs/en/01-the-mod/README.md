# The mod

**Better Experience - ALL In One** bundles several quality-of-life improvements.

## Where everything is

- **Right-click the floor or a piece of furniture** > **Better Experience - ALL In One**: organize your base, food by expiration, map search, GPS and this manual.
- **On the map** (M key): the **Assistant** button, with the **Items** and **Favorites / GPS** tabs.
- **Options** > **Mods** > **Better Experience - ALL In One**: every setting and the hotkeys.

## Hotkeys

No key is bound by default, so the mod never clashes with other mods. Pick yours in **Options > Mods > Better Experience - ALL In One > Hotkeys**.
