# Item search

Your character takes notes of what is inside the containers the game has shown you. Later you ask the map where an item is.

## How to search

1. Open the map (M key) and click **Assistant**, **Items** tab.
2. Type what you are looking for, in English or Portuguese: **knife**, **hammer**, **ammo**, **faca**...
3. The list shows the buildings that have the item, with distance and direction.

## Buttons

- **Show**: centers the map on the place.
- **Highlight**: the furniture glows when you get close.
- **Walk to**: your character walks to the furniture. Only works inside the same building.
- **Forget**: erases everything that was noted (click twice to confirm).

## What the search knows

Only containers you have **seen up close**, that is, that showed up in the loot panel. Each result says how long ago it was seen.

## Options

- **Record seen containers**: turn off to stop taking notes.
- **Update radius**: every 3 seconds, notes again the known containers within this radius. 0 = loot panel only.
