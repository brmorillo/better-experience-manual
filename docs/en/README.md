# Getting started

Welcome to the **Better Experience - ALL In One** manual: the mod's guide plus a community-made guide to Project Zomboid Build 42.

## What is here

- **The mod**: everything Better Experience does and how to use it.
- **Skills**: every skill in the game, grouped by the same categories as the skills screen.
- **Items**: weapons, tools, food, clothing, medicine, books, bags and electronics.
- **Actions**: driving, building, cooking, looting and getting safe water.
- **Character**: occupations, traits, moodles and health.
- **World**: map, zombies, power and water, weather and animals.
- **Better Survival**: the trench and stealth from the Better Survive mod (needs the mod enabled).

## How to use this manual

Click a folder in the list on the left to open or close it. Use the search box to look through every page, community tips included.

> This manual is written by the community. Use **Edit this page** to improve the official text, or **Add a tip** to leave your own tip at the end of the page.
