# Saúde e ferimentos

Abra o painel de saúde para ver cada ferimento. Limpe e faça curativo; troque curativos sujos. Vidro e balas precisam ser retirados.

Uma **mordida** de zumbi transmite a infecção, que é fatal. Arranhões e cortes de zumbi também têm uma chance de infectar.
