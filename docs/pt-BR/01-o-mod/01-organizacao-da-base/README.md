# Organização da base

O assistente guarda os itens nos móveis certos da sua base. Você só diz o que vai em cada lugar.

## O que nunca é mexido

Itens **favoritos**, **equipados**, **roupas vestidas**, itens na **hotbar** e **chaves** ficam sempre com você.

## Opções

- **Raio da base**: até quantos tiles do personagem os móveis marcados contam.
- **Andares acima/abaixo**: quantos andares entram na base (inclui porões).
- **Organizar o conteúdo das bolsas**: também guarda o que está dentro da mochila.
- **Parar se houver zumbi perto**: interrompe se um zumbi aparecer.
